# Monday, Reviewed in One Line

![make.fun](https://make.fun/badge/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1.svg)
![rank](https://make.fun/badge/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1/cemplon11/makefun-monday-reviewed/rank.svg)
![reward](https://make.fun/badge/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1/cemplon11/makefun-monday-reviewed/reward.svg)

A tiny deterministic Python program that writes a one-line product-style
review of Monday to `/output/entry.txt` — one star, 43 unread emails, a
58-minute "quick sync", and the worst subscription ever, because it
auto-renews every week.

Competition: [Monday, Reviewed in One Line](https://make.fun/c/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1)

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Pure Python standard library; no dependencies, no network, same output
on every run.
